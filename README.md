# GeoDetector_FelipeCordova_202502

Este repositorio contiene el código y los materiales asociados al pipeline GEODETECTOR.

## Estructura de carpetas

- `Codigo Fuente/`
  - Contiene los scripts Python utilizados en el pipeline de procesamiento, entrenamiento, predicción, sincronización GPS/video y generación de reportes.
  - Incluye los archivos refactorizados para ejecutar el flujo completo como módulo independiente.

- `Conferencia/`
  - Contiene el código LaTeX del paper para la presente conferencia.
  - Incluye todos los archivos necesarios para compilar el documento (`paper.tex`, `sample.bib`, `IEEEtran.cls`, `compile.sh`, figuras, y archivos auxiliares generados por la compilación).
